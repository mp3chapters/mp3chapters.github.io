Chapter Format Converters

Free online tools for converting between MP3 chapter formats. All processing happens locally in your browser.

Audio Converters

MP3 → M4B

Convert a chaptered MP3 file to M4B audiobook format.
MP3 → MP4 Video

Create a slideshow video from an MP3 with chapter images.

Extract Chapters from MP3

MP3 → Podlove XML

Extract chapters from an MP3 and export as Podlove Simple Chapters.
MP3 → Podcast JSON

Extract chapters from an MP3 and export as Podcast Namespace JSON.
MP3 → Plain Text

Extract chapters from an MP3 as a plain text list.

Convert Between Chapter Formats

Podlove XML → JSON

Convert Podlove Simple Chapters XML to Podcast Namespace JSON.
JSON → Podlove XML

Convert Podcast Namespace JSON to Podlove Simple Chapters XML.
Podlove XML → Text

Convert Podlove Simple Chapters to a plain text list.
JSON → Plain Text

Convert Podcast Namespace JSON to a plain text chapter list.
Text → JSON

Convert a plain text chapter list to Podcast Namespace JSON.
Text → Podlove XML

Convert a plain text chapter list to Podlove Simple Chapters XML.
